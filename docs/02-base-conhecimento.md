# Base de Conhecimento

# Estratégia de Dados: 
A base utiliza dados estruturados e mockados localmente para garantir total segurança e privacidade de informações sensíveis.   Fontes Utilizadas:

 transacoes.csv: Histórico de entradas e saídas para análise de hábitos de consumo. 
 
 historico_atendimento.csv: Para manter o contexto de dúvidas e frustrações anteriores. 
 
 perfil_investidor.json: Define a tolerância ao risco (Conservador, Moderado, Arrojado).
 
 produtos_financeiros.json: Catálogo de opções de investimento e crédito recomendáveis.
